# TALENTOPS-TEST
este proyecto es un test de nivel practico para talentOps

## Instalación
 - realizado con ultima version de node (v22.13.1 al momento de creacion de este archivo)
```cmd
 npm install 
 ```

## Uso
```cmd
 npm run start:dev
 ```


## Documentación de la API

Al correr el proyecto puedes ingresar a [Swagger](http://localhost:3000/document) para ver la documentación.
